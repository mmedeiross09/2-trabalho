Como o processo funciona

  1. Escolhemos um conjunto de caracteres visíveis: letras, números e símbolos.
  2. Cada caractere recebe uma posição dentro dessa tabela.
  3. A cifra desloca essa posição pela chave informada.
  4. Na descriptografia, o deslocamento é invertido para voltar ao valor original.

Criptografar: novo índice = (índice + chave) % 95

Descriptografar: índice original = (índice - chave + 95) % 95

Exemplo rápido

A → índice 10 → +7 → índice 17 → H

Ao descriptografar, H volta para A usando a operação inversa.
